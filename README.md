# How US elections work

A free reference page explaining US elections for people outside the US —
midterm coverage for Election Day, Tuesday, November 3, 2026.

- Static single page (`index.html`), no build step, no tracking, free for all readers.
- Midterm odds refresh automatically every day from Kalshi market data
  (see `.github/workflows/update-odds.yml`).
- Results section updates as results arrive, with final results planned
  for November 7, 2026.

Published with GitHub Pages: https://vitingupta.github.io/Us-election2026/
